# امور مشتریان ۳ — نسخه قدیمی

این مخزن نسخه‌ی مستقل و اولیه‌ی CRM است و دیگر منبع اصلی توسعه نیست.

نسخه‌ی فعال و یکپارچه‌ی محصول اکنون در این ساختار ادامه پیدا می‌کند:

- فروشگاه: `Asroom7/crm-storefront`
- پنل مدیریت واحد: `Asroom7/crm-storefront/panel`
- بک‌اند و دیتابیس مرکزی: `Asroom7/crm-backend`

قابلیت‌های ارزشمند این نسخه به پنل یکپارچه منتقل یا با معماری مرکزی جایگزین شده‌اند. این مخزن فعلاً فقط برای حفظ تاریخچه و امکان بازگشت نگه داشته شده و نباید قابلیت جدیدی در آن توسعه داده شود.
